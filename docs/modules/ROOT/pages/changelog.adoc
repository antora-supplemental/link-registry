== 2026-10-23

=== v0.1.1 extension fixes

* The Antora extension now receives its `registry` option (Antora passes `{ config, playbook }` only to a one-argument `register`).
* Literal warnings use each component version's own registry, so a name defined in one component's `antora.yml` no longer flags pages in other components.
* xref:changelog-details/2026-10-23 - extension fixes.adoc[Details]

=== v0.1.0 initial release

* `link-registry` CLI: `check`, `fix`, `suggest`, `list`, `hook install`; teaching error messages and GitHub Actions annotations.
* Composite action and reusable workflow with a sparse, install-free first job that gates build and deploy through `needs:`.
* Antora extension: registry injection, literal warnings, and the `_/link-registry/index.json` outbound link index.
* xref:changelog-details/2026-10-23 - initial release.adoc[Details]
